Entry for the make.fun bounty "The Funniest Honest Appliance Error": a Python program that writes one line to `entry.txt` — the honest error message a washing machine with an unbalanced load could show, in the machine's own flat, put-upon voice. The fault is real (an unbalanced load makes a washer vibrate and walk across the floor); the laugh comes out of the truth of it.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
